Your password and authenticator key stay in this Chrome profile. Anyone with access to the profile may be able to read them. Set this up on a device you control.

Your Purdue account

Use the account you want this extension to choose whenever you sign in.

Enter the full address, including @purdue.edu.

Connect your authenticator

Add a separate authenticator for the extension. Keep your existing sign-in method until this one works.

Open Microsoft Security info
  1. Sign in with using your existing method.
  2. Choose Add sign-in method, then Microsoft Authenticator.
  3. Choose I want to use a different authenticator app, then Can’t scan QR Code?
  4. Copy the Secret key and paste it below. Leave Microsoft’s setup page open.

Use the secret key, not a six-digit code. An otpauth://totp/ setup link also works.

Finish on Microsoft’s page

On Microsoft’s page, choose Next to move past the QR code. Enter this code to verify the new authenticator.

You’re ready to sign in.

The extension will choose this account and complete supported Purdue sign-in forms for you.

Try Purdue Brightspace

To use another account, pause automatic sign-in from the extension popup first. Reload any sign-in page that was open before setup.

Clear saved settings

Remove your saved email, password, and authenticator key from this extension.

You’ll need to set up the extension again.
